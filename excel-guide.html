Learn Excel Step by Step

A simple introduction to spreadsheets, formulas and basic data analysis.

1. What is Microsoft Excel?

Microsoft Excel is a spreadsheet application used to organize information, perform calculations and analyze data.

An Excel worksheet contains rows, columns and cells. Each cell has an address, such as A1 or B2.

2. Your First Excel Table

Imagine you are tracking the prices of products in a small shop.

ProductQuantityPrice
Notebook35
Pen42
Folder24

You can enter this information into Excel cells and use formulas to calculate totals.

3. Four Useful Excel Formulas

SUM — Add numbers

To add values from cells B2 to B4:

=SUM(B2:B4)

AVERAGE — Calculate the average

To calculate the average of values from B2 to B4:

=AVERAGE(B2:B4)

MIN — Find the smallest value

=MIN(B2:B4)

MAX — Find the largest value

=MAX(B2:B4)

4. Practice Exercise

Enter these numbers into cells A1, A2 and A3 in Excel:

10
20
30

Now try these formulas in other cells:

  • =SUM(A1:A3) — expected result: 60
  • =AVERAGE(A1:A3) — expected result: 20
  • =MIN(A1:A3) — expected result: 10
  • =MAX(A1:A3) — expected result: 30
